# 重聚巅峰 - 6V6 狂野脚本 AI 生成 Skill（测试版）

## 它能做什么

输入你的 12 只出战精灵、精灵解析、套装与推理强度，即可生成一套重聚巅峰脱机 6V6 狂野脚本：`BP.ini（禁用/首发/出战）`、`切换.ini（死切/中切/击杀切/等）`、以及每只精灵的精灵出招`\*.ini`。
内置属性克制、主流套装、规则术语、战术体系、精灵定位、旧版开源出招样本等参考资料，产出附带完整克制分析与设计思路。

## 核心能力
1. 端到端编排:
从数据准备、对策推理、脚本生成到校验交付，一条流水线跑通。

2. 精准数据:
SeerAPI 数据库提供精灵/技能权威 ID，名称以数据库为准，不编造。

3. 规则明确:
50 回合、GBK/CRLF、5 技能携带、击杀单招、切走不相邻等硬规则内置。

4. 阵容联动:
识别前场/主力/拦截/辅助/后场定位与体系，尝试规划联防与切换链。

5. 子 agent 加速:
智能分多组进行并行加速推理，主 agent 负责整合与校验。

6. 阵容推荐:
给出你的精灵池，可额外推荐 1~3 套 12 只阵容并附组队理由。

## 安装与使用
把本包内三个技能文件夹（`seer-chongju-strategy`、`build-seerapi-encyclopedia`、`build-chongju-scripts`）一并复制到 agent 的 /skills 文件夹中（本包已包含后两个子技能）。或直接让 agent 代为安装。
需要访问 GitHub 的网络环境以下载精灵数据库。
