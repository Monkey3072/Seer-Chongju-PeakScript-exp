# 构建赛尔号精灵文本图鉴（SeerAPI）

从 SeerAPI 官方数据库构建按筛选清单过滤的《赛尔号》精灵文本图鉴。

## 输入与输出

- **筛选清单**（txt，UTF-8）：每行一条 `ID-名称`；其他非空行视为分组标题（如"六星半 核心主力"）。
- **数据库**：`seerapi-data.sqlite`；缺失时从 `https://github.com/SeerAPI/api-data/releases/download/latest/seerapi-data.sqlite` 下载。
- **输出**：一份 UTF-8 文本图鉴，每只精灵一个条目、按清单分组排列，**不含"图鉴"与"简介"条目**。

## 工作流

1. 确认筛选清单与数据库就绪；数据库缺失先下载到工作目录。
2. 运行提取脚本（一次性完成提取与清洗）：

   ```bash
   python scripts/build_encyclopedia.py --db <sqlite> --filter <清单> --output <输出.txt>
   ```

   脚本内置：清单解析、字段提取、低级技能过滤、删除图鉴/简介、同名查重、技能追加 ID、输出统计与自校验。

3. 核对脚本输出统计：清单精灵全部命中、无"未找到"、每只精灵各一条种族值与一条魂印、无技能清空、无 ID 重复。
4. 交付到 `outputs/`；删除下载的数据库等中间文件，保留 skill 自带脚本。

## 输出格式（字段已对照数据库核实）

每只精灵固定为：

```text
【5000】圣灵谱尼
  属性：神灵
  性别：无性别
  种族值：体力 180 ／ 攻击 110 ／ 防御 120 ／ 特攻 150 ／ 特防 120 ／ 速度 140 ／ 总和 820
  魂印：
      · 虚无：自身受到攻击伤害后，免疫下1次受到的技能伤害（boss无效）
  技能：
    5级 虚无-20498（属性技能·普通, 威力 0, PP 1, 命中 100%, 必中）
      描述：自身进入了虚无状态
```

技能行：`<学习等级>级 <技能名>-<技能ID>（<分类>·<属性>, 威力, PP, 命中, 先制, 必中, 暴击率）【第五技能/特训/神谕】`。

## 低级技能过滤（保守）

同时满足以下条件才删除，否则保留：

- 解锁等级 ≤ 15（`--max-level` 可调）
- 无先制等级
- 无任何技能说明与效果描述
- 物理/特殊攻击（属性技能不删）
- 威力 30~70（`--min-power` / `--max-power` 可调）
- 非必中，且非特训/神谕/第五技能

调整阈值前，先运行 `python scripts/calibrate_low_skill_rules.py --db <sqlite> --filter <清单>` 查看技能分布。

## 查重规则

同名不同 ID（普通/神谕·觉醒双形态）只保留一条：优先保留名称含"神谕"/"觉醒"者，否则保留 ID 较大者。种族值/魂印数值相同但属于不同精灵的，属正常巧合，不去重。
