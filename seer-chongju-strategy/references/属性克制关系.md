## 双属性克制系数计算公式

### 单属性攻击双属性
1. 防守方双属性拆为两个单属性 B 和 C
2. 分别查表获得系数1和系数2
3. 最终系数：
   - 系数1=系数2=2 → 最终=4
   - 至少有一个=0 → 最终=(系数1+系数2)/4
   - 其他情况 → 最终=(系数1+系数2)/2

### 双属性攻击单属性
同"单属性攻击双属性"，拆分攻击方双属性为两个单属性 B 和 C。

### 双属性攻击双属性
1. 拆分防守方双属性为 C 和 D
2. 按"双属性攻击单属性"规则分别计算 双属性A·B 对 C 和 D 的系数
3. 最终系数 = (系数1+系数2)/2（无双≥2或含0的分类讨论）

## 快速查询方法

当需要判断精灵A对精灵B的属性克制时：

1. 从 JSON 数据中获得双方的"属性"字段
2. 若含空格则为双属性（如"混沌 圣灵"），拆分处理
3. 按上述公式查表计算，结果为：4/2/1/0.5/0.25/0
4. 结果≥2 为"克制"，≤0.5 为"微弱/无效"
