# 精灵昵称 → 正式名 → ID 对照表

本表用于把战术体系、玩家口语、旧列表中的**昵称/别名/错别字**统一解析到
`seerapi-data.sqlite` 的**正式名称与 4 位精灵 ID**。

解析优先级（硬规则，见 SKILL.md）：

1. 以 `seerapi-data.sqlite` 的 `pet.name` 为正式名、`pet.id` 为权威 ID。
2. 用户提供「ID + 名称」冲突时，**以名称为准**反查 ID。
3. 名称仍匹配不到时，用 LLM 模糊匹配数据库中最相近的正确名称，并**回写标注为“模糊匹配”**。
